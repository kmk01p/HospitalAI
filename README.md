# HospitalAI
### 📌 프로젝트 개요

이 프로젝트는 대전광역시에 있는 요양병원, 일반병원, 치과병원, 한방병원의 현황 데이터를 수집하여 통합하고, 이를 기반으로 데이터 분석을 수행하는 작업입니다. 지역 의료 인프라의 분포나 병원 유형별 통계 등을 파악할 수 있도록 데이터를 정리하고 가공합니다.

### 🛠 사용 기술 및 도구

- **Python**, **Pandas**, **NumPy**
- **CSV 파일 처리 및 병합**
- *CP949 인코딩 및 천 단위 콤마 처리(thousands=',')**를 포함한 로컬 데이터 정제

### 💡 기대 효과 및 활용 방안

- 지역 의료기관의 분포나 병상 수, 병원 수 등을 비교할 수 있어, 정책 수립이나 보건 행정에 활용 가능
- 추가적으로 시각화나 위치 기반 분석(GIS 등)으로 확장하면, 더 의미 있는 인사이트 도출 가능
